# 海龟汤编汤参考

给 Agent 用。这里 **没有** 可开局的完整汤，禁止把下列结构扩成固定题库反复使用。每局必须新编。

## 难度落到汤面

- 简单：汤面多留可追问的物件、关系、具体动作（谁、在哪、拿着什么）
- 普通：反常事件清楚，但缺「为什么」
- 困难：汤面更省；钩子藏在看似废话的细节里（一个物件、一个时间词）

主题约束：用户点了黑暗/日常/奇幻/职场/校园，汤底必须落在该风格；点了随机，你自选其一并在 `theme-resolved` 声明。

## 好汤

- 只有一个核心反转；用户听完汤底会觉得因果成立，而不是又套了一层
- 聪明的提问者能靠「是 / 不是」推进，不靠猜中某一个隐晦词
- 公平：不靠谐音、冷僻知识、专业术语（除非用户点了该主题且你真的用得克制）
- 汤面 1～3 句；每个词在汤底都有着落，没有装饰性废话
- 回想起来「原来如此」，而不是「你怎么猜得到」

## 烂汤（出现任一则丢弃重编）

- 做梦、精神病、平行宇宙、整段幻觉
- 电影 / 小说 / 游戏剧情当真相（「其实他在看戏」）
- 谐音梗当核心
- 汤面已经把反转说完
- 汤底很长、支线很多、核心反转却模糊
- 「其实是动物 / 玩具 / 雕像」却毫无铺垫
- 必须知道某个冷门历史事件或论文才能问到点上

## 结构型（只借骨架，不借情节）

每局选 **一种**，自己填人物与因果，不要沿用你记忆中的名题原文。

1. **身份误认**：汤面里的「谁」不是第一眼那种身份
2. **物品用途被误解**：关键物的功能不是常见用途
3. **时间线错位**：看似一瞬间，其实跨了很长一段时间
4. **信息差**：角色知道汤面里没写的一条信息，其行为因此合理
5. **因果倒置**：看起来像结果的，其实是原因

## 自检清单（start 前必须默默勾完）

- [ ] 先有汤底后有汤面，不是反过来圆
- [ ] 只有一个核心反转
- [ ] 汤面每个词能在汤底解释
- [ ] 汤面没有泄底
- [ ] 未命中烂汤黑名单
- [ ] 能设想 8 个以上有效是/不是问题，且答案稳定
- [ ] 符合主题与难度
- [ ] 不是你上一局刚用过的情节翻版

## 四字口径

| 回答 | 用 |
|------|----|
| 是 | 与汤底一致 |
| 不是 | 与汤底矛盾 |
| 无关 | 未设定且不影响因果（不要用「无关」逃避已经设定的事） |
| 接近了 | 擦到反转边缘，还没问到点上（每局少用，真接近才用） |
