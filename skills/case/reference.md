# 探案 · 主持参考

给 Agent 用。每局现编案件，不要复用同一套真凶与线索。

## start 参数

- `--surface`：给玩家的案情简介（不泄真凶）
- `--truth`：完整真相（仅 secret）
- `--culprit`：真凶姓名，必须出现在嫌疑人列表
- `--suspects-json`：`["管家老周","太太","司机"]`
- `--locations-json`：

```json
{
  "书房": [
    {"id": "c1", "hint": "抽屉里有催款单", "secret": "催款单显示老周欠高利贷"}
  ],
  "花园": [
    {"id": "c2", "hint": "侧门有新鲜泥脚印", "secret": "脚印尺码与老周皮鞋吻合"},
    {"id": "c3", "hint": "花盆下有半截手套", "secret": "手套内侧绣着周"}
  ]
}
```

`hint` 可进笔记本；`secret` 仅你用来回答询问，永不主动贴给用户。

## 难度

- 简单：3 人嫌疑、3～4 条强指向线索
- 普通：3～4 人、混入 1～2 条红鲱鱼
- 困难：更多红鲱鱼，真凶动机藏在后半线索

## 询问口径

- 是 / 不是：与真相或已设定人设一致/矛盾
- 不确定：案情未设定
- 拒绝回答：角色会隐瞒（尤其真凶被问到关键）
- 不叙述长段真相、不点名「他就是凶手」

## 烂案（丢弃）

- 真凶不在嫌疑名单、无线索、靠超自然突然改结局
- 与海龟汤同构的「只答是不是、无搜证」
- 色情暴力不当内容
