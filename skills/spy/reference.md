# 谁是卧底 · 主持参考

给 Agent 用。词对每局新选，不要反复用同一对。

## 好词对

- 同类、易混淆：牛奶/豆浆、火车/地铁、眼镜/墨镜、篮球/足球
- 两词长度接近，日常可描述，不靠冷僻知识
- 卧底词与平民词必须不同

## 烂词对（丢弃）

- 完全无关（苹果/火箭）——局崩，无法伪装
- 同义词几乎无法区分又毫无描述空间
- 专有名词 / 色情暴力不当内容
- 直接把身份写进词里

## NPC 扮演

- 用 `npcword --seat` 只给自己看
- 描述 1 句，点到物品特征即可，不要说「我是平民」
- 投票：平民倾向投描述最可疑者；卧底可带节奏但不要明牌

## 用户座位

- `myword` 只打印词面，不打印「平民/卧底」标签
- 不要主动告诉用户「你是卧底」；让投票与描述去发现
